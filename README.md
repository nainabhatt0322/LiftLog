# LiftLog — PWA

Installable web-app version of LiftLog.

Features:
- 5-day workout checklist
- Exercise timers
- Calendar-based workout dates
- Permanent dated history
- Skip and unskip dates
- Reset only completed exercises for the selected date
- Delete history by date
- Responsive laptop/phone UI
- Installable as a PWA
- Offline cache after first successful load
- Local browser storage; no account/backend required

For installation, host the folder over HTTPS. Android Chrome can use Install/Add to Home Screen. iPhone Safari can use Share → Add to Home Screen.
